## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the proxy server:
   `npm run proxy`
3. Run the app:
   `npm run dev`
4. Open your browser and navigate to `http://localhost:3000` to access the visualizer UI, the proxy server will forward WebSocket connections to the target server specified in the UI. Proxy Address (WebSocket) should be set to `localhost:8081`.
